# KiriPDF — Local PDF Atelier

> 完全無料・外部API利用ゼロ。ブラウザ内で安全に動作する高機能PDF編集ツール

## 特徴
- **完全無料 & API通信ゼロ**: 有料APIや外部サーバーへの通信は一切発生しません。すべてのPDF処理（抽出、分割、結合、暗号化）は利用者のブラウザ（PCのメモリ内）で実行されます。ライブラリ・フォントもすべて同梱しており、外部CDNへの通信もありません。
- **情報漏洩リスク ゼロ**: 機密書類、個人情報、校務文書も安心して扱えます。
- **自由なページ抽出・結合**: 複数ファイルにまたがる離れたページ同士を選んで1つのPDFにまとめられます。
- **並べ替え・回転**: 選択した順番がそのまま出力順になります（出力設定画面でドラッグ／▲▼で変更可）。ページごとの90°回転にも対応。
- **全ページ一括分割**: 1ページごとの個別PDFに切り分け、ZIPファイルで一括ダウンロード。
- **標準準拠のパスワード暗号化**: AES-256 / RC4 暗号化による閲覧パスワード付与（印刷・コピーは許可、編集は禁止）。
- **用紙サイズ & 向きの統一**: A4/A3/B5/B4/Letter規格、および「すべて縦向き」「すべて横向き」への自動センタリング配置。
- **校外秘スタンプ（透かし）**: 日本語（漢字・ひらがな）に対応した鮮明な電子スタンプ。
- **メタデータ消去**: タイトル・作成者・作成アプリの情報を空にして出力。
- **アプリとしてインストール可能（PWA）**: 一度開けば、以降はオフラインでも動作します。

## 制限事項
- **編集制限付きのPDF**（開くのにパスワードは不要だが、編集・印刷などが制限されているもの）は閲覧のみ可能で、抽出・分割・結合には使えません。ファイル一覧に鍵アイコンが表示されます。
- **閲覧パスワード付きのPDF**は読み込めません。
- 「用紙サイズの統一」を使うと、リンク・フォーム入力欄・注釈（コメント）は保持されません。
- 透かしは画像として重ねているだけなので、PDF編集ソフトで取り除くことができます。持ち出し防止の抑止表示としてお使いください。

## 使い方
1. `index.html` をブラウザで直接ダブルクリックして開くか、Web に公開します（下記）。
2. PDFファイルをドラッグ＆ドロップして読み込みます。
3. 必要なページを出力したい順にクリックして選択し、「選択抽出」をクリックして出力設定を適用します。

## Web に公開してアプリとしてインストール（PWA）
GitHub Pages で公開します（GitHub の無料プランでは、リポジトリを公開（Public）にする必要があります）。

1. リポジトリの **Settings → General** の最下部「Danger Zone」→「Change repository visibility」で **Public** にします。
2. **Settings → Pages** で「Deploy from a branch」→ `main` / `/ (root)` を選んで保存します。
3. 数分後に `https://<ユーザー名>.github.io/kiri-pdf/` を開きます。以後 `main` にプッシュすると自動で更新されます。

※ 公開されるのはツールのコードだけです。利用者が読み込むPDFは端末の外に送信されません。

### インストール
- **Windows / Mac（Chrome・Edge）**: 画面右上の「アプリをインストール」ボタン、またはアドレスバー右端のインストールアイコン。
- **iPhone / iPad（Safari）**: 共有ボタン →「ホーム画面に追加」。
- **Android（Chrome）**: メニュー →「アプリをインストール」。

2回目以降はネット接続なしで起動できます。PCでインストールした場合、PDFの「プログラムから開く」に KiriPDF が表示されます（Chrome / Edge）。

AES-256 暗号化は HTTPS 上、または直接ファイルを開いた場合に使われます。暗号化なしの `http://` で公開すると RC4 に切り替わります。

## 開発メモ
- 同梱ライブラリ: pdf-lib 1.17.1 / PDF.js 3.11.174（日本語表示用 CMap を含む）/ @pdfsmaller/pdf-encrypt 1.2.0 / JSZip 3.10.1 / Lucide 1.58.0（`vendor/`、ライセンスは `vendor/licenses/`）
- CSS は Tailwind CSS 3.4.17 で事前生成しています。`index.html` のクラスを変更したら `npm install && npm run build:css` で `css/tailwind.css` を再生成してください。
- 同梱ファイルを変更して公開する際は、`sw.js` の `CACHE_VERSION` を上げてください（上げないとインストール済みの端末が旧版のまま動きます）。
- claude.ai のアーティファクト版は `python3 scripts/build-artifact.py` で `artifact/` に生成します（Service Worker を外し、保存は downloads capability 経由）。
